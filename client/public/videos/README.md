# Hero Video Placement

Drop your video file directly into this folder with the name:
`hero.mp4`

Full local path on your PC:
`c:\Users\USER\Desktop\permium\client\public\videos\hero.mp4`

Or in the public root:
`c:\Users\USER\Desktop\permium\client\public\hero.mp4`

The homepage hero video player will automatically load and loop it continuously with zero volume/play/pause buttons!
